# FrozenLake Reinforcement Learning

Implementation of tabular **Q-learning** and **SARSA** for the 8×8 slippery FrozenLake environment, prepared for AICL 407 Lab 1.

## Environment

- Environment: `FrozenLake-v1`
- Map: 8×8
- Slippery transitions: enabled
- Episode time limit: 200 steps
- States: 64
- Actions: 4 (LEFT, DOWN, RIGHT, UP)
- Goal reward: +1; other transitions: 0

The 200-step limit is set explicitly in `make_env()`. Use this helper when creating the environment for training so that local tests and experiments use the same configuration.

## Project files

| File | Purpose |
|---|---|
| `qlearning.py` | Environment setup, epsilon-greedy policy, update rules, and training loop |
| `tests/` | Unit tests for the update equations and exploration schedule |
| `experiments.py` | Runs the multi-seed learning-curve and learning-rate experiments |
| `outputs/learning_curves.png` | Q-learning and SARSA learning curves |
| `outputs/alpha_sweep.png` | Comparison of learning rates |
| `outputs/summary.txt` | Numerical experiment summary |
| `outputs/report.pdf` | Four-page lab report generated from the experiment results |


## Run the experiments

The full experiment uses 100,000 episodes per run, five seeds, and five learning rates. The alpha=0.1 runs are shared between the learning-curve and learning-rate analyses to avoid repeating identical training runs.

```powershell
python experiments.py
```

By default, four worker processes are used. On a slower computer, reduce the number of workers:

```powershell
python experiments.py --workers 2
```

The script creates the `outputs` directory and generates:

- `learning_curves.png`: mean moving success rate and standard-deviation band across five seeds for each algorithm.
- `alpha_sweep.png`: mean final-1,000-episode success rate and standard deviation for each learning rate.
- `summary.txt`: per-algorithm numerical results and the seed-0 Task 4 check.
- `report.pdf`: a four-page report containing the environment, methods, experimental plots, results, and conclusion.

For a quicker software check, a smaller episode count can be used, for example `python experiments.py --episodes 5000 --workers 2`. Use the default 100,000-episode run for the final lab results.

## Algorithm notes

**Q-learning** is off-policy. For a non-terminal transition, its target uses the largest estimated action value in the next state:

`target = reward + gamma * max(Q[next_state])`

**SARSA** is on-policy. Its target uses the value of the next action selected by the current epsilon-greedy policy:

`target = reward + gamma * Q[next_state, next_action]`

For an environment transition marked `terminated=True`, both updates use only the immediate reward. A time-limit `truncated=True` transition is treated separately so the update can bootstrap from the next state.
